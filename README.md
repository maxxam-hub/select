# Docker compatibility tests for SelectOS

## Описание

В рамках тестового задания были реализованы автоматизированные проверки для базовых сценариев работы Docker в среде SelectOS.  
Цель тестов - убедиться, что Docker корректно работает с ключевыми компонентами системы: сетью, томами и механизмом публикации портов.

Тесты реализованы как автоматизированные сценарии, которые взаимодействуют напрямую с Docker Engine через API.

---

# Реализованные проверки

### ТК_1 - взаимодействие контейнеров в пользовательской сети

Проверяется:

- создание пользовательской Docker-сети
- подключение контейнеров к сети
- сетевое взаимодействие контейнеров по имени

Контейнер `container1` выполняет `ping` контейнера `container2`.  
Успешный ответ подтверждает корректную работу сети Docker.

---

### ТК_2 - сохранение данных в Docker volume

Проверяется:

- создание Docker volume
- запись файла в volume
- удаление контейнера
- повторное подключение volume к новому контейнеру
- сохранность данных

Если файл остаётся доступным, значит volume работает корректно.

---

### ТК_3 - проброс портов контейнера

Проверяется:

- запуск контейнера nginx
- публикация порта контейнера на хост
- доступность сервиса с хоста через HTTP-запрос

Если `curl` получает ответ от nginx - проброс портов работает корректно.

# Используемые инструменты

Для реализации автоматизированных тестов использованы:

**Python 3**

Язык программирования для написания тестов.

**pytest**

Фреймворк для написания и запуска тестов.

Используется для:

- структуры тестов
- выполнения тестовых сценариев
- формирования отчётов.

**Docker SDK for Python**

Библиотека для работы с Docker Engine API.

**requests**

Используется для проверки HTTP-доступности сервисов.

# Как запустить проект локально

## 1. Требования

- установлен Docker
- установлен Python 3.9+
- Docker daemon запущен

Проверить:

```bash
docker info
```

---

## 2. Установка зависимостей

Установить зависимости:

```bash
pip install -r requirements.txt
```

---

## 3. Запуск тестов

```bash
pytest -v
```

---
