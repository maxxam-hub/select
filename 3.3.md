# Проверка совместимости Docker с SelectOS

Цель: убедиться, что Docker корректно устанавливается и работает в среде SelectOS, а также взаимодействует с основными компонентами системы (systemd, сеть, файловая система).

---
## Проверка установки Docker
- [ ] Проверить установлен ли Docker и его версию
```bash
docker --version
```
Ожидаемый результат: отображается установленная версия Docker.
---
- [ ] Проверить информацию о Docker

```bash
docker info
```
Ожидаемый результат: Docker daemon отвечает и выводит информацию о системе.
---
## Проверка интеграции Docker с systemd
- [ ] Проверить статус сервиса Docker
```bash
systemctl status docker
```
Ожидаемый результат: сервис активен (`active (running)`).
---
- [ ] Проверить включён ли автозапуск сервиса
```bash
systemctl is-enabled docker
```
Ожидаемый результат: сервис находится в состоянии `enabled`.

## ТК_1: проверка взаимодействия контейнеров в пользовательской сети Docker
**Цель:**  
Проверить, что контейнеры, подключённые к одной пользовательской сети Docker, могут взаимодействовать друг с другом.

**Предусловия:**
- Docker установлен и запущен
- пользователь имеет права на выполнение Docker команд
---
**Шаги теста:**
1. Создать пользовательскую сеть
```bash
docker network create test-network
```
2. Запустить первый контейнер в созданной сети
```bash
docker run -dit --name container1 --network test-network alpine sh
```
3. Запустить второй контейнер в той же сети
```bash
docker run -dit --name container2 --network test-network alpine sh
```
4. Проверить сетевое взаимодействие между контейнерами
```bash
docker exec container1 ping container2
```
---
**Ожидаемый результат:**
Контейнер `container1` успешно отправляет ICMP-пакеты контейнеру `container2`, и в выводе команды `ping` отображаются ответы от контейнера `container2`.  
Это подтверждает, что контейнеры могут взаимодействовать друг с другом внутри пользовательской сети Docker.
---
## ТК_2: сохранение данных в Docker volume
**Цель:**  
Проверить, что данные, записанные в Docker volume, сохраняются после удаления контейнера.
**Предусловия:**
- Docker установлен и запущен
- пользователь имеет права на выполнение Docker команд
---
**Шаги теста:**
1. Создать volume
```bash
docker volume create test-volume
```
2. Запустить контейнер с подключённым volume
```bash
docker run -it --name volume-test -v test-volume:/data alpine sh
```
3. Создать файл внутри volume
```bash
echo "test-data" > /data/file.txt
```
4. Выйти из контейнера
```bash
exit
```
5. Удалить контейнер
```bash
docker rm volume-test
```
6. Запустить новый контейнер с тем же volume
```bash
docker run -it --name volume-test-2 -v test-volume:/data alpine sh
```
7. Проверить наличие файла
```bash
cat /data/file.txt
```
---
**Ожидаемый результат:**
В выводе команды отображается содержимое файла:
```
test-data
```
## ТК_3 Проверка проброса портов контейнера
**Цель:**  
Проверить, что сервис внутри контейнера доступен с хоста через проброшенный порт.
**Предусловия:**
- Docker установлен и запущен
- пользователь имеет права на выполнение Docker команд
---
**Шаги теста:**
1. Запустить контейнер nginx с пробросом порта
```bash
docker run -d -p 8080:80 nginx
```
2. Проверить доступность сервиса с хоста
```bash
curl http://localhost:8080
```
---
**Ожидаемый результат:**
В ответе возвращается HTML-страница nginx.
---
